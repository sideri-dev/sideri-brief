Japan's top young-designer award just had its biggest year yet.

The Good Design New Hope Award, run by the same body that administers Japan's Good Design "G-mark," pulled in a record 1,060 entries this cycle — up about 59% from 668 the year before — with 146 entries winning and the single grand prize decided December 12. The organization's own reach into young and emerging design is clearly growing, not stagnant, which matters for anyone weighing whether that award circuit is worth entering down the line. One correction made along the way: the prior-year figure of 668 entries was originally traced to the wrong source page; the actual source confirms it, and the numbers stand.

Natura's ambient-capture ring finally has a price: $99 now, $9 a month later.

Natura's "Interface" ring launches at $99 — the company says it plans to raise that later — free for 3 to 6 months, then $9 a month, confirmed independently through TechCrunch's own reporting rather than just the company's page. That pencils out to roughly $207 in the first year, a concrete number for a device class (alongside Plaud and Amazon's Bee) that sells cheap hardware plus an ongoing subscription — the opposite of a one-time, unsubsidized purchase.

A hobbyist used Raspberry Pi's remote-access tool to track down a device that kept switching networks on him.

Builder Kat Shann's "OuijaCNC" project — an old Raspberry Pi 3 Model B+ running the new Raspberry Pi OS Trixie — isn't itself a serious comparable for anything built on a Raspberry Pi 5. But one detail is worth keeping: Shann used Raspberry Pi Connect specifically because the device kept moving between networks, and Connect let him find its current IP address whenever it came back online. That's a real, if small, data point on using Connect to manage an unattended device whose network identity isn't stable.

Yesterday's deep-dive

A closer look tested a content-authenticity (C2PA) signing design against the actual Python library that would run it on a Raspberry Pi, not just the written specification. The signing mode called for turned out to be unreachable through that library — a required setting is silently ignored on the signing path, confirmed by both reading the library's code and running it, so no valid "box hash" is ever produced. A second, sidecar-based hashing mode works end to end through the same library, is byte-for-byte reproducible, and caught a deliberate one-byte tamper test — the reachable half of the design turns out to be the safer half too. Outside the main reference-implementation family, only one independent verifier (written in PHP, built in direct response to a security researcher's public post) checks the full scope of what a signature excludes; every verifier a stranger could actually use to check a file shares that same blind spot. A related fix landed in the reference library on November 2 as an undocumented "VULN fix," but hasn't reached the Python package yet.
