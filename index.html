Today

1. A new paper shows how to keep an image-search index working when the user types a sentence instead of showing a picture.

FactEmbed separates a multimodal model's reasoning from the embedding it actually searches with, using a set of factorized latents that simulate the visual change a modification phrase describes, then beats prior methods across composed-image-retrieval benchmarks. It's a working architecture for exactly the text-plus-image hybrid that any image-search platform choosing between "search by picture" and "search by description" eventually has to decide between.

2. A label-free image search tool already running in production just published hard cost numbers.

Digital Collections Explorer — an open-source, metadata-agnostic "find more like this" tool built on OpenAI's CLIP model — has cleared peer review with real figures attached: a 562,842-image Library of Congress map collection, a 129,386-photo collection processed in an hour and a half on a single MacBook Pro, and a named cloud deployment cost of eight cents an hour. A usable cost and throughput anchor for what running something like this on a consumer device's own index would actually take.

3. A researcher trained a working segmentation model on just 19 hand-labeled architectural drawings.

Working from Rome's own archive of architectural drawings, a single researcher built a U-Net pipeline with a ResNet-34 backbone that generalises acceptably to drawings it never saw, starting from only 19 manually annotated examples. Real precedent for pulling usable structure out of a historical drawing collection too small to annotate by hand at scale — directly relevant to anyone trying to preserve architectural records for heritage buildings.

4. An archaeological survey alone just pushed a major Tokyo rail project back seven years.

Keikyu's grade-separation project through Shinagawa Station has slipped from a 2029 to a 2036 completion. The dominant reason named is how long the mandated archaeological survey of the Takanawa Embankment — the site of Japan's first railway, a nationally designated historic site — took to finish, compounded by other major projects (a Tokyo Metro line extension, the Chuo Shinkansen maglev) converging on the same ground. A real, dated figure for what thorough on-site documentation of a heritage site demands before redevelopment can proceed.

5. A Kumamoto earthquake report has an academic naming, almost word for word, why undesignated heritage buildings keep disappearing.

Hokkaido University's Shigeyasu Ikegami says undesignated buildings "quickly disappear" in Japan whenever disaster strikes, despite carrying real cultural value — illustrated in the same report by a one-of-a-kind 1864 military record that nearly vanished at an undesignated temple, found only because surveyors happened to look before it was gone. A disaster, not just redevelopment, can be the trigger that erases a building nobody got around to formally designating.

Yesterday's deep dive

Dug into StreamEmbed, a new paper for indexing a growing stream of screenshots in real time with no labels, and found the headline claim doesn't transfer as cleanly as it reads: every query in the paper is a written sentence, not an image, so it isn't actually an instance of image-to-image search, and its speed advantage comes from screen content barely changing between frames — a redundancy the authors themselves measured as nearly absent in ordinary camera footage (5.7% on kitchen footage versus 63–77% on screen recordings). Three things do carry over regardless: a stateless pruning step is separable from a lossy cross-frame cache that needs training; the shipped tool gates out near-duplicate frames before any pruning happens, work a change-detection layer already does elsewhere; and a 64-byte binary code searched real indexes of 55,900–63,500 vectors in 15.5ms on a laptop CPU, a smaller and more specific result than the paper's own table implies. Nobody has yet published the one number that actually decides whether any of this saves anything for a camera pointed at a mostly still scene.
