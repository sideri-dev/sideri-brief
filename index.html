Mbed TLS's own advisories page confirms 29 CVE-2026 entries against the crypto library version our firmware line has been pinned to.

A running watch on this gap has estimated "at least 18, likely 27–30" unpatched advisories since late August; today's direct count from Mbed TLS's own advisories page lands at exactly 29, including a named remote-buffer-overflow flaw in the TLS 1.2 ECDHE-PSK handshake (CVE-2026-50580). Both the currently pinned ESP-IDF release and the next one queued to ship sit on the same vulnerable Mbed TLS line. The open question is how many of the 29 are actually reachable in a real embedded configuration, not just present in the dependency tree.

Sensirion's SEK-SEN69C evaluation kit adds CO2 to its all-in-one air-quality sensor, reaching 10 environmental parameters in a single module.

It extends the SEN68 platform (particulate matter, VOC, NOx, HCHO, temperature, humidity) with CO2 sensing and a new evaluation SKU. It's a useful marker of how much environmental-sensing density a single commercial module now packs into one package, for anyone tracking this class of multi-gas sensor.

Melexis's MLX90617 reads a pot's base temperature straight through an induction hob's ceramic glass.

Unlike the imaging-array thermal sensors (MLX90640/90641) that show up often in cooking-hardware coverage, the MLX90617 is a single-point thermopile: factory-calibrated -0°C to 125°C at the sensor, reading cookware surfaces from 70°C to 250°C through the hob's ceramic glass via optical filtering tuned to that material. It ships in a TO39 package with an SMBus digital interface. Coverage is thin — Melexis's own site is currently unreachable, and the only writeup found is a syndicated mirror, so this stays single-source.
