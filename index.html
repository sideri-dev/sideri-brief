This week

Three independent measurements converged this week on the same finding for always-on capture devices: the energy cost is almost entirely in physically waking the camera sensor, not in running whatever model processes the image afterward — OpenGlass's own open-source power logs, a Raspberry Pi 5 benchmark, and one of Meta's own power models for its Aria smart glasses all point the same way, and the chip maker behind OpenGlass's own coordinator chip has since gone bankrupt. Separately, GoPro's own securities filing showed that a parts-allocation cut — not a price increase — is what actually stranded $39.6 million of inventory it couldn't cancel, a reminder that on a tight hardware supply chain, getting cut off from parts is the live risk, not paying more for them; the same week, Raspberry Pi's own documentation disclosed a running board revision that quietly swapped an onboard Ethernet chip. And a widely-discussed "any file can fake a valid signature" finding against the C2PA content-provenance standard turned out to have already been patched in the reference library before the researcher who found it even published — though a modified version of the same trick still works today.

Yesterday's deep dive

An earlier deep-dive into that provenance-forgery claim found the original headline wrong in an interesting way: "no fix has shipped" wasn't true — a real fix had shipped eleven days before the researcher's own post, and the standard verification tool now rejects his exact proof-of-concept unmodified. But the underlying attack class survives in modified form: a tiled version of the same trick still produces a technically "valid" signature covering zero actual file content, because the fix checks where a signed section sits rather than how much of the file it actually covers. The publicly hosted verification tool the researcher pointed readers toward is itself frozen on an old, unpatched version of the library, which is why his claim read true to anyone checking it in the field. The finding splits an underlying design choice cleanly: keeping a signature in a file separate from the photo itself comes out vindicated as solid; signing a hash that covers the whole file is the half still exposed to this class of attack.
